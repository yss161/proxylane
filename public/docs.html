API Docs

所有接口为 GET，CORS 全开，无需 API Key。单次最多返回 5000 条。

端点

端点说明
/v1/proxies主接口，支持全部筛选参数与 7 种输出格式
/v1/all.txt全部代理，纯文本 ip:port
/v1/http.txt仅 http 协议
/v1/https.txt仅 https 协议
/v1/socks4.txt仅 socks4 协议
/v1/socks5.txt仅 socks5 协议
/v1/random随机返回一条；?format=json 返回结构化数据
/v1/stats总量、协议分布、来源健康状态
/v1/sources源清单及其最近一次抓取结果
/v1/config站点配置、支持的格式与参数（供前端读取）
/v1/health存活探针

查询参数

参数取值说明
formatjson / txt / csv / clash / base64 / surge / singbox默认 json
protocolhttp,https,socks4,socks5 或 socks逗号分隔多选
countryISO 两位国家码逗号分隔多选，如 US,JP
anonymitytransparent / anonymous / elite匿名度
sourcemonosans / proxifly / …按来源过滤
max_latency毫秒仅返回有延迟数据且低于该值的条目
verifiedtrue / false仅上游已验证
sortquality / latency / country / random默认 quality
limit1–5000默认值随格式变化
offset≥0分页偏移

响应头

Header说明
x-total-count符合筛选条件的总条数
x-returned本次实际返回条数
x-total-pool整个池子的条数
x-dropped-unsupported目标格式不支持而被剔除的条数

示例

# 只要美国 & 日本、延迟低于 800ms 的前 50 条
curl "https://proxy.hanser.cv/v1/proxies?country=US,JP&max_latency=800&limit=50" 

# Clash 订阅
curl "https://proxy.hanser.cv/v1/proxies?format=clash&verified=true&limit=500" -o proxylane.yaml

# 随机一个 socks5
curl "https://proxy.hanser.cv/v1/random?protocol=socks5"
