API Docs

所有接口为 GET，CORS 全开，无需 API Key。单次最多返回 5000 条。

端点

端点说明
/v1/proxies主接口，支持关键词搜索、全部筛选参数与 7 种输出格式
/v1/all.txt全部节点，纯文本分享链接（一行一个）
/v1/ss.txt仅 Shadowsocks
/v1/vmess.txt仅 VMess
/v1/vless.txt仅 VLESS
/v1/trojan.txt仅 Trojan
/v1/hysteria2.txt仅 Hysteria2
/v1/random随机返回一条；?format=json 返回结构化数据
/v1/stats总量、协议分布、国家清单、来源健康状态
/v1/countries国家/地区清单与节点数（前端下拉框用）
/v1/sources源清单及其最近一次抓取结果
/v1/config站点配置、支持的格式与参数
/v1/health存活探针

查询参数

参数取值说明
q任意字符串搜索名称 / 主机 / SNI / 协议 / 分享链接
formatjson / txt / csv / clash / base64 / surge / singbox默认 json
protocolss,ssr,vmess,vless,trojan,hysteria2,tuic,anytls,socks5逗号分隔多选
countryISO 两位国家码逗号分隔多选，如 US,JP
networktcp / ws / grpc / h2 / quic …传输层
securitynone / tls / reality安全层
sourceaggregator / nomorewalls / …按来源过滤
max_latency毫秒仅返回有延迟数据且低于该值的条目
verifiedtrue / false仅 TCP 探活通过的节点
sortquality / latency / country / name / random默认 quality
limit1–5000默认值随格式变化
offset≥0分页偏移

响应头

Header说明
x-total-count符合筛选条件的总条数
x-returned本次实际返回条数
x-total-pool整个池子的条数
x-dropped-unsupported目标格式不支持而被剔除的条数

示例

# 搜美国 Reality 节点
curl "https://proxy.hanser.cv/v1/proxies?q=US&protocol=vless&security=reality&limit=20"

# Clash 订阅（已探活）
curl "https://proxy.hanser.cv/v1/proxies?format=clash&verified=true&limit=300" -o proxylane.yaml

# 随机一条 vless
curl "https://proxy.hanser.cv/v1/random?protocol=vless"
